# Licence scope

The author authorised the following split on 19 October 2026. Repository
visibility remains private. This licensing change does not publish the work.

| Material | Licence |
|---|---|
| Project-owned software in src/, scripts/ and tests/, software configuration and CI | MIT; see ../LICENSE and ../LICENSES/MIT.txt |
| Project-owned research documentation, aggregate result tables and original illustrations | CC BY 4.0; see ../LICENSES/CC-BY-4.0.txt |
| Third-party material, MHR-derived control metadata and template illustrations | Applicable upstream terms and notices; see third_party.md |

The Python package licence describes its software. CITATION.cff lists both
project licences because the repository also carries research documentation and
aggregate material. Citation of the paper is appreciated; it is not an added
condition of the MIT licence.

The v0.2.0 tag and existing release archive retain their original CC BY 4.0
licensing. Existing CC BY permissions are not withdrawn. This split applies to
the current project-owned files; no third-party work is relicensed.

The project licences grant no rights over source datasets, participant meshes,
fitted participant parameters or private records. Such material remains absent.
The separate Apache-2.0 notices for MHR and clad-body are retained unchanged.

The prepared Hugging Face companion uses CC BY 4.0 for its project-owned data
and documentation, MIT for its invented example code, and upstream notices for
template-derived illustrations. Its README identifies each scope. Preparing the
package does not upload it or change the visibility of any remote repository.
